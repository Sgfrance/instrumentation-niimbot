Scanner, vérifier, confirmer.

Le téléphone conserve le scanner. Le PC reçoit le lot, puis l’ouvre dans Power Apps pour confirmation.

Qui utilise ce téléphone ?

Choisissez le prénom du destinataire. Changer de prénom conserve le lot en cours de chacun.

Préparer la liaison

Ouvrez ensuite le lien privé sur le téléphone choisi. Le lien reste valide jusqu’à révocation. Gardez la page du téléphone au premier plan.

Préparez la liaison sur le PC.

Envoyer la fiche

Le scan doit être terminé dans les 30 minutes. Le lot reçu reste à contrôler dans Power Apps.

Collez une seule fois le lien de votre application globale, depuis ses détails dans Power Apps. Ce n’est pas le lien de l’ancienne application mobile.

Touchez votre prénom ou Activer le son. Le bip fonctionne lorsque cette page est ouverte au premier plan.

Le montage sera confirmé sur le PC. Vous restez sur cette page pour le véhicule suivant.

Lot reçu

Contrôler sur le PC

Importer dans Power Apps
Pour garder la fiche ouverte : copiez le lot, collez-le dans Power Apps et cliquez sur Charger le lot. Le lien d’import reste disponible en secours. Importation ≠ enregistrement. Le bouton de confirmation dans Power Apps effectue l’enregistrement SharePoint. Libérez ce lot seulement après avoir confirmé ou annulé dans Power Apps.
